How does MarineoClash work?

The app uses external screen capture, computer vision and emulator touch inputs. It does not modify game memory. This does not guarantee protection from detection or account penalties.

What do I need to run it?

A Windows 10 or 11 x64 PC, LDPlayer or MuMu, and Clash of Clans. Use 1600 × 900 landscape game frames at 300 DPI. Python is bundled. Native capture uses the selected installed emulator’s vendor DLL; other emulators remain unsupported.

Is Free a separate download?

No. Download v2.1.1 and start in Free mode. Enter a valid key in Bot Manager’s License / Updates to unlock Pro in the same app. Saved configs survive expiry; extra configs remain editable and can be unchecked to meet Free limits.

Where do I get my license after paying?

Stripe redirects you to the delivery page, which retrieves your key from the licensing service. Copy the complete key into the app’s License tab. You can also check your email for delivery. If it takes a moment, keep the confirmation page open.

Can each account have its own settings?

Yes. Use SET for each config and check the accounts to run. Free supports five configs per bot, with one village type across the checked plan. Pro supports 50 configs per bot and both villages in one plan. Continuous cycles and account resume are Free too.

Can I move my license to another PC?

A license is bound to one PC. Use the app’s license deactivation and transfer controls when changing machines. Contact Discord support if you need help.
